# ddeprivedd-releases

**ddeprivedd.os** is a Windows desktop app that cleans temp files, trims background RAM usage, and
tunes your PC's performance. It includes a RAM limiter you can point at specific apps, a whitelist to
protect the programs you don't want touched, and a deep clean that clears temp files, empties the
recycle bin and closes non-whitelisted background apps in one click.

A valid key is required to use the app. If you don't have a key, you can buy one [https://ddeprivedd-os-site.pages.dev/](here).
## Installing

Download **`ddeprivedd-os-setup.zip`** from the latest release, extract it, and run `loader.exe`.

Already installed? The app updates itself automatically - you don't need to come back here.
